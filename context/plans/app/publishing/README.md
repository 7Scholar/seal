# Intent

## What & why

Everything around the code that a public, open-source, trustworthy release demands — the chunk of work the root intent explicitly names as planned work, not an afterthought: the repository README with installation and getting-started, the documentation a stranger needs to understand and trust the project, CI enforcing the quality gates (fmt, clippy with denied warnings, tests, audit), packaging and code-signing/notarization for the platforms Seal ships on, the release process, and whatever else maintainability by strangers requires (license, contribution guidance). It is done when a stranger can discover, install, verify, and contribute to Seal without any private context.
